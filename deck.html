Writing code

Four ideas carry the whole week

  • A value: 8.8
  • An object keeps it under a name: x <- 8.8
  • A function works on it: mean(x)
  • A package brings more functions: library(tidyverse)
Writing code

Why a script, and not just the Console

  • It is the record of what you did, step by step
  • Run it again tomorrow, on next quarter's data
  • A colleague can read it, check it, and run it too
The copy-paste problem

How most reports are made today

  • The chart is copied from R into Word
  • The numbers are typed into the sentences
  • Next quarter, it is all done again, by hand
  • One wrong paste, and nobody can trace it back
The idea

What if the report were the script?

Enter Quarto

Quarto: your words and your R code in one file

  • One file, report.qmd: text, plus chunks of R
  • Render it: Quarto runs the code and writes the document
  • HTML, Word, PDF and slides from the same file
  • Free, built into Positron, and it works offline

Afterword

Telling the story

The report renders. Now make it say something to the person who reads it.

Two kinds of chart

Exploratory charts are for you; explanatory charts are for them

  • Exploratory: fast, many, rough, thrown away
  • Explanatory: slow, few, finished, made for one reader
  • A report needs the second kind. Quarto renders either; you choose
Before any chart

Write the big idea in one sentence

  • What happened: Jazan's unemployment rose 2.1 points
  • So what: every other region fell over the same years
  • Now what: look closer at Jazan next quarter
story.qmdstory.html
Titles

A title that states the finding

  • Descriptive: Unemployment rate by region, 2022 to 2025
  • Message: Jazan rose while every other region fell
  • Write the message title last, once you know what the chart shows
  • In a parameterised report, compute it by a rule, or keep it descriptive
Five more examples

Five questions a manager asks, five ways to answer

  • Where do we stand? A ranking, with the Kingdom as the yardstick
  • What changed? Two moments, one line per region
  • One region, or many? Small multiples instead of spaghetti
  • When did it turn? An annotation on the moment
  • Does it need a chart at all? Sometimes a sentence and a table

What every example did

Six moves, whatever the chart

  • Start from the default chart, then remove what does not help
  • Grey for the context, one colour for the point
  • Draw the yardstick in: the Kingdom, the first quarter
  • Label the data itself, not a legend
  • State the finding in the title, computed from the data
  • Round every number before it goes into words
For a manager

A briefing in five slides

  • The number: one figure, on its own
  • Why it moved: one chart, with a message title
  • What is at risk if nothing changes
  • The choice: two or three options
  • The ask: what you need from the room

On an offline machine

Five settings that keep everything working

  • embed-resources: true: one HTML file with everything inside
  • html-math-method: mathml: formulas without the internet
  • theme_html(portable = TRUE): tinytable's styles from the package
  • font-paths: fonts: Typst finds the fonts in the project
  • No chalkboard in the deck you send
