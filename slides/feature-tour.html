What Revealjs can do

Everything here is one .qmd file. Its source is shorter than you expect.

Run this deck, do not describe it. Move fast — thirty seconds a slide.

Then open feature-tour.qmd and scroll it once, slowly. That contrast is the whole reveal.

This is a local, vendored version of Quarto’s own demo deck, rebuilt on the GASTAT brand with the course data. quarto.org is not reachable from CML.

Pretty code

unemp |>
  filter(region == "Jazan") |>
  mutate(gap = rate - kingdom$rate) |>
  ggplot(aes(date, gap)) +
  geom_col(fill = "#00B050") +
  theme_gastat()

Syntax highlighting, a copy button, and the brand’s own colours.

Point at the copy button. People do not expect a deck they can copy code out of.

Code animation

ggplot(jazan, aes(date, rate))

Press right. The next slide is the same block with two lines added, and Reveal tweens between them. This is auto-animate="true" on both slide headings.

Code animation

ggplot(jazan, aes(date, rate)) +
  geom_line(colour = "#00B050", linewidth = 1.2) +
  theme_gastat()

Line highlighting

unemp |>
  filter(region != "Kingdom") |>
  group_by(region) |>
  summarise(change = last(rate) - first(rate)) |>
  arrange(change)

Press right four times. Each press walks the highlight down the pipeline — filter, then group, then the summary.

This is how you explain a pipeline to a room without them losing their place. Written as code-line-numbers="|2|3-4|5".

Slide transitions

This one zoomed. none, fade, slide, convex, concave, zoom — set for the deck, overridden per slide.

Set one for the deck and leave it. A deck where every slide transitions differently is a deck nobody can follow.

The keyboard is the interface

Key What it does
s Speaker view — notes, timer, next slide
b Chalkboard — draw on the slide
c Notes canvas
g Jump to slide
o Overview of every slide
r Scroll view — the deck becomes a page
f Full screen

Do all seven, live, now. This is the part of the tour people actually remember.

Press b and draw a circle round a number. Press r and scroll the deck as a document. Press s so they see this very note on the presenter screen.
