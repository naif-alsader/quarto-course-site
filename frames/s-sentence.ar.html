```{r}
#| include: false
library(tidyverse)
library(tinytable)
change <- read_csv("unemployment.csv") |>
filter(region != "Kingdom") |>
group_by(region) |>
summarise(first = first(rate),
last = last(rate)) last = last(rate)) |>
mutate(change = last - first) |>
arrange(desc(change))
```
Unemployment fell in `r sum(change$change < 0)` of
`r nrow(change)` regions. The exception is
`r change$region[1]`: up `r change$change[1]` points,
to `r change$last[1]`%.to `r change$last[1]`% (@tbl-change).
```{r}
#| label: tbl-change
#| tbl-cap: "Unemployment rate by region, %"
change |>
select(Region = region,
`First quarter` = first,
`Last quarter` = last,
`Change, points` = change) |>
tt() |>
format_tt(digits = 1, num_fmt = "decimal",
num_zero = TRUE) |>
style_tt(i = 1, bold = TRUE, color = "#00803A") |>
theme_html(portable = TRUE)
```
