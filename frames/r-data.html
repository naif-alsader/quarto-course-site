1
read_csv() reads the file into a table and reports what it found: 224 rows, 4 columns, and each column's type: chr for text, dbl for numbers, date for dates.
2
glimpse() shows every column on one line: its name, its type and its first values. Run it first on any data you have not seen before.
3
filter() keeps the rows that pass a test: Jazan's 16 quarters. == asks: is it equal? |> hands the table on to the next function; read it as: then.
4
select() keeps the columns you name, in the order you name them. filter() chooses rows; select() chooses columns. Each |> adds one more step.
5
mutate() adds a column worked out from the others: the change since the first quarter. first() is the column's first value; round() keeps one decimal.
6
A new question, the same verbs: every region in the latest quarter, max(date), sorted. arrange() sorts from low to high; desc() turns it round, so Jazan comes first.
7
group_by() splits the table by region, and summarise() makes one row for each: here its first rate and its last. Jazan went from 9 to 11.1.
8
pull() takes one column out of the table as plain numbers, and last() keeps the last of them. Stored as latest, the number is ready to go into a sentence.
9
str_glue() writes a value into the text, where the braces are. Next quarter's data, the same line, a new number: that is how a Quarto report writes its sentences.
