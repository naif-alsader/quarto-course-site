1
Lines typed in the Console are gone tomorrow. A script keeps them in a file. To start one, press New at the top, then New File...
2
Positron asks what kind of file. Choose R File; the same list makes Python files and Quarto documents.
3
An empty R script opens in the editor, above the Console. It has no name yet: Untitled-1.
4
Type the code into it. The dot on the tab means the file has changes that are not saved yet.
5
Press Ctrl+S, type the name analysis.R and press Enter. The file now sits in the Explorer, next to the data, ready to run again any day.
6
library(tidyverse) loads the tidyverse: a family of packages for reading, shaping and charting data, readr, dplyr and ggplot2 among them.
7
read_csv() reads the file. |> passes the data on to filter(), which keeps the Kingdom's rows. Each line stores its result with <-.
8
Select the lines and press Ctrl+Enter: they run in the Console, top to bottom, exactly as if you typed them.
9
Now rates, kingdom and latest are in Variables: 224 rows of data, the Kingdom's 16, and its latest rate, 6.6.
10
The last line draws the chart, and it appears in Plots.
11
View(rates) opens the data as a table: every column, its type, and its spread.
