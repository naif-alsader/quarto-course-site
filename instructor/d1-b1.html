02Try it

Your turn · 5 minutes

Start your own report.qmd

  1. In Positron: File → New File → Quarto Document. Save it as report.qmd in a folder with unemployment.csv.
  2. Paste the code below and press Render, or run quarto render report.qmd in the terminal.
  3. Add toc: true and embed-resources: true, render again, and check the folder: one HTML file.
  4. Delete the blank line before the list, render, and see the list break. Put it back.

## Summary

Unemployment **fell** in most regions between 2022 and 2025.
*Jazan* is the exception. This note shows the national
trend and the latest rates.[^1]
The data cover:

- 13 regions and the Kingdom as a whole
- 16 quarters, from 2022 Q1 to 2025 Q4

Official figures are on the [GASTAT website](https://www.stats.gov.sa).

[^1]: All figures in this note are synthetic, made for training.

## Method

The unemployment rate is

$$
u = \frac{U}{U + E} \times 100
$$

where $U$ is the number unemployed and $E$ the number employed.

## Data

```{r}
library(tidyverse)
rates <- read_csv("unemployment.csv")
glimpse(rates)
```

## Trend

```{r}
kingdom <- rates |> filter(region == "Kingdom")
ggplot(kingdom, aes(date, rate)) + geom_line()
```
