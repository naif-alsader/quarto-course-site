02The R you need, on one page

Every function the two R builds use, and what it does. They come back all week.

read_csv()Reads a CSV file into a table
glimpse()Every column on one line: its name, its type, its first values
|>Hands the result on to the next function: read it as then
filter()Keeps the rows that pass a test, such as region == "Jazan"
select()Keeps the columns you name
mutate()Adds a column worked out from the others
arrange(), desc()Sorts the rows, low to high or high to low
group_by(), summarise()One row for each group
pull(), first(), last()One column out as numbers, then one value from it
str_glue()Writes a value into text, where the braces are
ggplot(), aes()The data, and which column goes on which axis
geom_line(), geom_col(), labs()Added with +: a line, bars, then the titles

03Try it

Your turn · 5 minutes

Start your own report.qmd

  1. In Positron: File → New File → Quarto Document. Save it as report.qmd in a folder with unemployment.csv.
  2. Paste the code and press Render, or run quarto render report.qmd in the terminal.
  3. Add toc: true and embed-resources: true, render again, and check the folder: one HTML file.
  4. Delete the blank line before the list, render, and see the list break. Put it back.

## Summary

Unemployment **fell** in most regions between 2022 and 2025.
*Jazan* is the exception. This note shows the national
trend and the latest rates.[^1]
The data cover:

- 13 regions and the Kingdom as a whole
- 16 quarters, from 2022 Q1 to 2025 Q4

Official figures are on the [GASTAT website](https://www.stats.gov.sa).

[^1]: All figures in this note are synthetic, made for training.

## Method

The unemployment rate is

$$
u = \frac{U}{U + E} \times 100
$$

where $U$ is the number unemployed and $E$ the number employed.

## Data

```{r}
library(tidyverse)
rates <- read_csv("unemployment.csv")
glimpse(rates)
```

## Trend

```{r}
kingdom <- rates |> filter(region == "Kingdom")
ggplot(kingdom, aes(date, rate)) + geom_line()
```
