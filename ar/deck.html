  1. في Positron افتح File → New File → Quarto Document، واحفظ الملف باسم report.qmd في المجلد نفسه اللي فيه unemployment.csv.

حول تقرير ربعي واحد إلى ملف Quarto

  • انقل كود R إلى ملف .qmd مع setup chunk يحمّل tidyverse في البداية
  • استبدل كل رقم تكتبه يدوياً بـ inline R داخل النص
  • أضف docx عشان ملف وورد، وtypst عشان ملف PDF

على جهاز دون إنترنت

خمسة إعدادات تخلي كل شيء يشتغل

  • embed-resources: true: ملف HTML واحد، وكل شيء داخله
  • html-math-method: mathml: المعادلات تظهر دون إنترنت
  • theme_html(portable = TRUE): تنسيقات جداول tinytable جاهزة في الحزمة نفسها
  • font-paths: fonts: Typst يلقى الخطوط داخل مجلد المشروع
  • والعرض اللي ترسله، لا تخلّي فيه chalkboard (السبّورة)
