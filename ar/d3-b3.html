---
title: "Unemployment in the regions"
subtitle: "Quarterly briefing · synthetic data"
params:
  region: "Jazan"
format:
  revealjs:
    logo: gastat-logo-color.png
    footer: "Unemployment briefing · synthetic data"
    slide-number: true
    embed-resources: true
---

```{r}
#| include: false
library(tidyverse)
rates <- read_csv("unemployment.csv")
kingdom <- rates |> filter(region == "Kingdom")
jazan <- rates |> filter(region == "Jazan")
focus <- rates |> filter(region == params$region)
change <- rates |>
  filter(region != "Kingdom") |>
  group_by(region) |>
  summarise(change = last(rate) - first(rate))
up <- change |> filter(change > 0) |> pull(region)
```

## Unemployment is falling

::: {.incremental}
- Down in `r sum(change$change < 0)` of `r nrow(change)` regions since 2022
- It rose only in `r up`
