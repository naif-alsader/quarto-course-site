```{r}
#| include: false
library(tidyverse)
rates <- read_csv("unemployment.csv")
kingdom <- rates |> filter(region == "Kingdom")
jazan <- rates |> filter(region == "Jazan")
change <- rates |>
  filter(region != "Kingdom") |>
  group_by(region) |>
  summarise(change = last(rate) - first(rate))
up <- change |> filter(change > 0) |> pull(region)
```

## Unemployment is falling

::: {.incremental}
- Down in `r sum(change$change < 0)` of `r nrow(change)` regions since 2022
- It rose only in `r up`
:::
